# HIS Plan 2026 — DTWU / เมืองสมุทร

แผนโครงการ HIS 3 Site (DTMU · DTWU วลัยลักษณ์ · เมืองสมุทร/สมุทรปู่เจ้า) ในรูปแบบเว็บ

## เปิดใช้งาน
**ประตูเข้าเดียว:** [`index.html`](index.html) — หน้าปก + การ์ดเด่น + สารบัญ 48 หน้า
กรองตามไซต์/หมวด/ชนิด และค้นหาได้ในหน้าเดียว
(`html/index.html` เดิมยังเปิดได้ จะพากลับมาที่นี่ให้เอง)

ทุกหน้าใน `html/` มีแถบเมนูร่วมกัน — ปุ่มกลับสารบัญ · เมนูหมวด ·
**ปุ่มสลับไซต์ไปหน้าเดียวกันของอีกไซต์** และกด <kbd>/</kbd> ที่หน้าไหนก็ได้
เพื่อเปิดช่องค้นหาด่วนแล้วกระโดดข้ามหน้า

## โครงสร้าง
```
index.html      ★ สารบัญ/หน้าแรก — สร้างการ์ดทั้งหมดจาก html/nav.js
html/           หน้าเว็บแผน 49 ไฟล์
  ├─ nav.js      ★ แหล่งข้อมูลเดียวของเมนู — ทะเบียนหน้า + ตัวสร้างแถบเมนู
  ├─ style.css   โครงร่วมของหน้าเอกสาร (39 หน้า)
  ├─ slide.css   โครงร่วมของสไลด์นำเสนอ (9 หน้า)
  └─ index.html  redirect กลับไปหน้าแรก (ลิงก์เก่าไม่เสีย)
deliverables/   เอกสารส่งมอบ
  ├─ dtwu/      งวด M1-M4 · templates/ (html) + docx/
  └─ samut/     งวด 1-3 · templates/ (html) + docx/
```

## ระบบสไตล์
| โครง | ใช้กับ | ความกว้าง |
|---|---|---|
| `style.css` | หน้าเอกสาร 39 หน้า | `.wrap` 1120 · `.wrap.w-narrow` 960 · `.wrap.w-wide` 1400 |
| `slide.css` | สไลด์ 9 หน้า | `.slide` 16:9 · `.slide.wide` A4 แนวนอน (ตารางกว้าง) |

สีประจำไซต์ประกาศ 2 ที่และต้องตรงกันเสมอ — `:root` ใน `style.css` กับ `AY_SITES` ใน `nav.js`
(DTMU `#5b9bd5` · DTWU `#9560b8` · เมืองสมุทร `#2f7cc4` · งานกลาง `#c08a1e`)

## เพิ่มหน้าใหม่
1. สร้างไฟล์ `html/ชื่อไฟล์.html`
2. ใส่ `<div id="ay-nav"></div>` ไว้บนสุดของเนื้อหา และ `<script src="nav.js"></script>` ก่อน `</body>`
3. เติม 1 บรรทัดใน `AY_PAGES` ของ [`html/nav.js`](html/nav.js)

จบ — สารบัญ เมนูทุกหน้า ตัวกรอง และช่องค้นหา จะรู้จักหน้าใหม่เองทั้งหมด
(ตั้ง `b:` ให้ตรงกับหน้าของอีกไซต์ ถ้าอยากให้มีปุ่มสลับไซต์)
