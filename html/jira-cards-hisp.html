คิวงานรอบนี้ — ดูจาก JQL
project IN (WUH, MSH) AND summary ~ "Flow" AND status IN ("In Review", REOPENED)
ORDER BY updated ASC

ตอนนี้มี Flow ที่ยังไม่เสร็จรวม 22 ใบ (Epic WUH-6 จำนวน 10 · MSH-68 จำนวน 12) เจ้าของทั้งหมดคือชมพู่

เกณฑ์ผ่าน (ใช้กับ Flow ทุกใบ)
  • AS-IS ตรงกับที่ รพ. ทำจริง (เทียบกับที่เดินดูหน้างาน)
  • ครบทุกขั้นตอน ไม่ข้ามจุดที่ต้องคีย์ซ้ำหรือทำงานนอกระบบ
  • ระบุผู้ทำแต่ละขั้น และเอกสาร/ฟอร์มที่ใช้จริง
  • TO-BE อ้างหน้าจอ HA.OS ที่มีอยู่จริง ไม่ใช่หน้าจอที่เดาขึ้นมา
  • จุดเชื่อมต่อกับโมดูลอื่นและระบบภายนอกถูกต้อง
  • จุดที่ยังเป็น Gap/Config ระบุครบ พร้อมผู้รับผิดชอบ
วิธีทำงานกับสถานะ — เต เปลี่ยนสถานะที่การ์ด Flow เอง
  • ชมพู่ เขียนเสร็จ → เปลี่ยนการ์ด Flow เป็น In Review
  • ผ่าน → เต กด Done ที่การ์ด Flow ใบนั้นเอง (In Review → Done)
  • ไม่ผ่าน → เต กด Reopen (In Review → REOPENED) พร้อม comment ระบุข้อที่ไม่ผ่าน
  • ชมพู่ รับกลับไปแก้ → In Progress → ส่ง In Review อีกครั้ง
กติกา
  • รีวิวเสร็จภายใน 7 วัน นับจากวันที่การ์ดเข้าสถานะ In Review — เกินกว่านั้นให้ยกเข้า Daily
  • ตีกลับต้องระบุว่าข้อไหนไม่ผ่านและต้องแก้อะไร ไม่ใช่แค่ “ยังไม่โอเค” — เขียนเป็น comment ในการ์ด Flow ใบนั้น
  • ตีกลับได้ 1 รอบ ผู้เขียนแก้และส่งกลับภายใน 2 วันทำการ
  • รอบที่ 2 ยังไม่ผ่าน → ยกให้คนอื่นเขียน ไม่ปล่อยวนจนกินเวลาทั้ง sprint

  • Flow ทุกใบที่ส่งเข้ามาในรอบนี้ได้รับการรีวิว
  • ไม่มีใบไหนค้างเกิน 7 วันโดยไม่มีความเห็น
  • ใบที่ตีกลับมี comment ระบุข้อที่ไม่ผ่านชัดเจน
  • ใบที่ผ่านถูกกด Done แล้ว — ทีม BR/FR รับไปทำต่อได้
  • ใบที่ตีกลับครบ 2 รอบแล้วยังไม่ผ่าน ยกเข้า Daily เพื่อเปลี่ยนผู้เขียน
